# 엇박 (Peer Spread Tracker)

해외 선행(Lead) Peer 그룹과 국내 후행(Lag) Peer 그룹의 주가 괴리를 섹터별로 추적한다.

- `sheet_groups.py` - 관심종목 시트의 표 구조를 옮긴 Peer 그룹 정의 (단일 출처)
- `peer_tracker.py` - yfinance로 2020년 이후 종가 수집 → 최근 6개월 스프레드 Z-Score + 장기 커플링 강도 → `frontend/public/dashboard_data.json`
- `catchup_backtest.py` - 2020년 이후 괴리 사례를 세어 국내가 실제로 따라잡았는지 검증 → `frontend/public/backtest_data.json`
- `kr_names.json` - 국내 티커 표시명 275개
- `frontend/` - React + Vite + Tailwind 대시보드 (라이트 미니멀, 카드 그리드)
- `analysis/` - 일회성 검증 스크립트 (커플링, 신호 백테스트, 데이터 커버리지)
- `scripts/` - 30분 주기 자동 갱신 설정 (launchd). 설치는 `scripts/README.md` 참고

## 그룹 구성

그룹 정의는 `sheet_groups.py`가 단일 출처다. 관심종목 시트의 표를 그대로 옮겼고,
국내(lag) 종목이 없는 표(아날로그 반도체, CPU, EDA, 우라늄, 데이터센터)는
스프레드를 계산할 수 없어 대시보드에서 제외한다. 현재 32개 그룹 486종목.

티커를 추가할 때는 `analysis/verify_sheet_tickers.py`로 가격 조회가 되는지 먼저 확인하고,
`analysis/validate_sheet_groups.py`로 그룹 응집도와 커플링을 검증한다.

### Lead(해외) 보강 원칙

해외 종목을 지역별로 나눠 국내 그룹과의 상관을 재보면 차이가 크다.

| 지역 | 종목수 | 동행 | 시차1일 |
|---|---|---|---|
| 대만 | 14 | **0.37** | 0.02 |
| 일본 | 39 | **0.35** | 0.02 |
| 미국 | 115 | 0.10 | 0.18 |
| 유럽 | 32 | 0.14 | 0.14 |

한국 장이 미국보다 먼저 닫히므로 미국 종목은 동행 상관이 구조적으로 낮고,
일본·대만은 장 시간이 겹쳐 같은 날 반응한다. 커플링 0.35 이상 그룹은 전부 아시아
Peer를 갖고 있었고, 아시아가 없는 그룹의 최대치는 0.28이었다.

그래서 해외가 1~3종목뿐이던 그룹에 아시아 Peer 16종목을 보강했다.

| 그룹 | 이전 | 이후 | 추가 |
|---|---|---|---|
| 변압기/전력기기 | 0.19 | **0.43** | 히타치, 미쓰비시전기, 후지전기, 후지쿠라 |
| 2차전지 | 0.23 | **0.37** | 파나소닉, 신에츠화학, 무라타, 아사히카세이, **CATL, BYD** |
| 통신 기자재 | 0.20 | **0.31** | 어드반테스트, 히타치, 파나소닉 |
| 식품 | 0.09 | 0.22 | 키코만, 아지노모토, 메이지 |
| 화장품/ODM | 0.16 | 0.23 | 시세이도, 코세, 라이온 |
| 스킨부스터 | 0.12 | 0.20 | 펩티드림 |

`weak` 등급 그룹이 사라지고 `strong`이 10개에서 13개로 늘었다.

### 중국은 대표주만 넣는다

2차전지는 중국이 실질적 리더다(CATL 세계 1위 셀, BYD 최대 전기차/배터리 수직계열).
그런데 종목을 늘리면 오히려 나빠진다.

| 구성 | 종목 | 커플링 |
|---|---|---|
| US+JP (중국 없음) | 6 | 0.34 |
| **+ CATL, BYD** | **8** | **0.37** |
| + 중국 셀 5종목 | 11 | 0.32 |
| + 중국 셀·소재 11종목 | 17 | 0.28 |
| 중국만 | 11 | 0.20 |

중국 A주는 내수 정책과 외국인 수급 제약으로 움직이는 부분이 커서, 종목을 늘리면
그 고유 변동이 인덱스를 희석한다. 개별 상관도 CATL 0.18 / BYD 0.21 수준으로
일본 Peer(0.24~0.36)보다 낮다. 그래도 대표주 2개는 순효과가 있다.

CATL은 선전 A주만 상장돼 있다. BYD는 홍콩(1211.HK)이 선전(002594.SZ)보다 커플링이
약간 높고(0.37 vs 0.36) 외국인 거래도 자유로워 홍콩을 썼다.

추가할 때 확인한 두 가지가 있다.

**등급은 `max(동행, 시차1일)`이다.** 동행이 올라도 등급이 안 오를 수 있다. 미국
Peer가 지배하는 그룹은 전달이 `next_day` 채널인데, 아시아를 섞으면 동행은 오르지만
시차1일이 희석돼 순효과가 0이거나 음수가 된다. 후보 11개 그룹 중 5개(IP/엔터,
신재생, 방산 미국, 우주, 국내 원전)를 이 이유로 보류했다. IP/엔터는 동행이
0.04 → 0.21로 가장 크게 올랐지만 시차1일이 0.24 → 0.18로 떨어져 순효과가 -0.04였다.

**수치가 좋아도 업종이 맞아야 한다.** 후보 티커는 종목명과 업종을 전수 조회해
확인했고, 이 과정에서 4건을 걸렀다(`1919.HK`은 식품이 아니라 COSCO 해운,
`6208.T`/`6203.T`는 방산이 아니라 소형 기계, `9501.T`/`9503.T`는 전력 규제산업).

추가 종목은 전반기(2020~22)와 후반기(2023~) 양쪽에서 커플링이 올라가는지 확인했다.

## 1. 파이썬 데이터 수집

```bash
git clone https://github.com/nnaver2025-spec/peer.git
cd peer
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python peer_tracker.py
```

실행하면 그룹별 인덱스/스프레드/Z-Score가 콘솔에 찍히고 `frontend/public/dashboard_data.json`이 갱신된다.
데이터가 없는 티커는 경고만 남기고 그룹 계산에서 제외한다.

국내 종목은 티커 대신 종목명으로 표시한다. 매핑은 `kr_names.json`에 있고,
JSON에는 `{"ticker": "005930.KS", "label": "삼성전자", "missing": false}` 형태로 담긴다.
매핑에 없는 티커(해외 종목)는 티커를 그대로 쓴다.

계산 로직 단위 테스트는 네트워크 없이 돈다.

```bash
pip install -r requirements-dev.txt
python -m pytest tests/ -v
```

## 2. 프론트엔드 실행

```bash
cd frontend
npm install
npm run dev
```

`http://localhost:5173` 접속. 데이터만 갱신하려면 파이썬 스크립트를 다시 실행하면 되고, 프론트 재빌드는 필요 없다.

프로덕션 빌드는 `npm run build`, 확인은 `npm run preview`.

### 정적 호스팅 배포

서버 코드가 없어 `frontend/dist`를 그대로 올리면 된다. Cloudflare Pages를
GitHub 리포에 연결하면 푸시할 때마다 자동 배포된다.

| 항목 | 값 |
| --- | --- |
| 빌드 명령 | `npm run build` |
| 빌드 출력 | `frontend/dist` |
| 루트 디렉터리 | `frontend` |

하위 경로(`example.pages.dev/opsboard`)로 서비스하려면 `BASE_PATH`를 주고
빌드한다. 컴포넌트가 데이터를 `import.meta.env.BASE_URL`로 읽으므로 이 값만
맞으면 JSON 경로도 함께 따라간다.

```bash
BASE_PATH=/opsboard/ npm run build
```

데이터 갱신은 `.github/workflows/update-data.yml`이 30분마다 돌린다. 세 JSON이
git에 추적되므로 워크플로가 커밋하면 그 푸시로 재배포가 걸린다. 별도 배포
단계는 없다. 여론·백테스트 수집은 `continue-on-error`로 두어, 러너 IP가 막혀도
나머지 지표는 갱신된다. 커밋 전에 JSON 파싱을 확인해 깨진 payload가 올라가지
않게 막는다.

### 테마

헤더 오른쪽 토글로 다크/라이트를 바꾼다. 선택은 `localStorage`에 남고, 저장된
선택이 없으면 시스템 설정(`prefers-color-scheme`)을 따른다.

팔레트는 `index.css`의 `:root[data-theme='light']` 토큰이 전부 담당한다.
Tailwind 클래스가 `var(--color-*)`로 컴파일되므로 컴포넌트는 테마를 몰라도 된다.
예외는 SVG `stroke`처럼 속성으로 넘겨야 하는 색인데, `zone.js` / `fomo.js`가
hex 대신 토큰 이름(`--color-warn`)을 넘기고 `Sparkline`이 `var()`로 감싼다.

`index.html`에 테마를 미리 적용하는 인라인 스크립트가 있다. 이게 없으면 라이트
모드 사용자가 새로고침할 때마다 어두운 배경이 한 프레임 번쩍인다.

## 3. FOMO 여론 지표

8개 주식 커뮤니티에서 게시글 제목을 모아 탐욕/공포 키워드 빈도로 0~100 점수를 낸다.
50이 중립이고, 탐욕 쪽으로 기울수록 100에 가까워진다.

종목 하나를 바로 확인할 때는 CLI를 쓴다.

```bash
python fomo_scanner.py 삼성전자
python fomo_scanner.py 한화에어로스페이스
```

대시보드 `여론` 탭에 쓰이는 데이터는 감시 모드가 만든다.
대상은 각 그룹의 주도주(`bellwether_ticker`)이고, 중복을 빼면 30종목이다.

```bash
python fomo_watch.py            # 전체
python fomo_watch.py --limit 3  # 점검용
```

`frontend/public/fomo_data.json`이 갱신된다. 종목당 점수 이력을 60개까지 남기므로
탭에서 여론 변화를 추이선으로 볼 수 있다. 자동 갱신은 `scripts/README.md` 참고.

### 점수 추이

이력을 두 종류로 남긴다.

| 종류 | 보관 | 용도 |
|---|---|---|
| `history` | 최근 36회차 (2시간 주기면 3일) | 짧은 구간의 등락 |
| `daily` | 최근 30일 | 한 달 추세 |

회차 이력을 그대로 한 달치(360포인트)로 늘리면 이력만 500KB가 되고, 100px 폭
그래프에 360개를 그려도 읽히지 않는다. 그래서 하루 평균 한 점으로 접어 같은 기간을
30포인트로 덮는다. 같은 날 여러 회차가 돌면 누적 평균으로 갱신한다. 마지막 값만
쓰면 그날 대표값이 우연히 걸린 한 회차에 좌우된다.

지수 카드는 일별을 기본으로 쓰고(두 점 이상 쌓였을 때), 시장 여론 추이는
`일별` / `회차` 버튼으로 오갈 수 있다. 선에 마우스를 올리면 해당 지점의 날짜와
점수가 나온다.

표본 부족으로 점수가 없는 회차(S&P500 등)는 점을 만들지 않는다. 빈 점을 넣으면
선이 끊긴다.

### 수집 대상과 기간

수집 범위는 **최근 3일**(`LOOKBACK_DAYS`)이다. 목록에서 작성 날짜를 함께 읽어
기간을 벗어난 글은 버린다.

페이지 수만 정하던 초기 방식은 소스마다 시간 폭이 제멋대로였다. 실측에서 디시는
2페이지가 반나절인데 아카라이브는 2페이지가 6년치(2020년 8월 글까지)였고,
S&P500 표본의 64%가 아카라이브였다. 6년 전 여론이 지금 지표에 같은 무게로
들어가면 소스 간 비교가 성립하지 않는다.

기본 페이지를 먼저 훑고 아직 기간 안이면 `max_pages`까지 더 들어간다. 한 페이지가
전부 기간 밖이면 목록이 최신순이므로 그 뒤는 볼 필요가 없어 멈춘다.

| 사이트 | 기본/최대 페이지 | 방식 |
|---|---|---|
| 네이버 증권 종목토론실 | 3 / 12 | requests |
| 디시 한국 주식 / 미국 주식 / 주식 / 실전주식투자 | 2 / 4 | cloudscraper |
| 아카라이브 주식 채널 | 2 / 3 | cloudscraper |
| 에펨코리아 주식·재테크 | 2 / 5 | requests + 브라우저 쿠키 (아래 참고) |
| 뽐뿌 증권포럼 | 2 / 4 (EUC-KR) | cloudscraper |
| 에펨코리아 주식 인기글 | 2 / 3 | requests + 브라우저 쿠키 (시장 심리 전용) |

최대 페이지는 실측으로 정했다. 디시는 검색 결과가 3페이지에서 소진되므로(4페이지째
3행) 더 들어갈 여지가 없고, 네이버 종목토론실은 활발한 종목이면 30페이지도 오늘
하루치라 깊게 들어가야 한다. 아카라이브는 페이지당 5일 남짓이라 2페이지로 충분하다.

날짜를 읽지 못한 글은 버리지 않고 남긴다. 파서가 깨졌을 때 표본이 통째로 사라지는
편이 오래된 글 몇 개보다 위험하다.

### 에펨코리아

에펨은 Cloudflare가 아니라 자체 보안 시스템(openresty)을 쓴다. HTTP 430으로 보안
페이지를 주고, 그 안의 WebAssembly 모듈(`/mc/mc.php`)이 서명을 만들어 `fm5`/`fm6`
쿠키를 심은 뒤 재요청해야 목록이 나온다. 쿠키 토큰은 HTML에 노출돼 있지만 그것만
심어도 통과하지 못한다(430이 429로 바뀔 뿐). wasm 실행이 실제 관문이라
`cloudscraper`로는 뚫리지 않고, 요청 간격을 8초로 벌려도 막혔다.

그래서 `fomo_fmkorea.py`가 브라우저를 한 번만 띄워 쿠키를 받고, 이후 요청은
`requests`로 처리한다. 실측에서 이 쿠키로 68회 연속 요청이 전부 200이었다
(1291건 수집, 64초). 쿠키는 6시간 캐시하므로 브라우저는 회차당 한 번, 3초 남짓
뜬다. 수집 과정 전체가 브라우저를 쓰는 게 아니라 관문 통과에만 쓴다.

주의할 점은 IP 차단이다. 짧은 시간에 요청이 몰리면 보안 페이지가 `차단 종류: 2`로
바뀌고, 이 상태는 브라우저로도 통과하지 못하며 20분 이상 유지된다. 그때 종목마다
브라우저를 띄우면 회차만 길어지고 차단이 더 늘어난다. 그래서 쿠키 발급 실패를
기록해 30분간(`FAILURE_COOLDOWN_SEC`) 재시도하지 않는다.

`playwright`가 설치돼 있지 않거나 차단 중이면 이 게시판만 조용히 건너뛴다.
브라우저 의존은 여기 한 곳뿐이다.

```bash
pip install -r requirements.txt
playwright install chromium   # 최초 1회
```

디시 갤러리 ID는 `krstock` / `stockus` / `neostock` / `jusik`을 쓴다.
`stock_new`은 2015년에 멈춘 아카이브 갤러리이고 `us_stock` / `stocks` / `stock_invest`는
존재하지 않아, 같은 성격의 활동 갤러리로 대체했다.
`neostock`만 일반 갤러리라 `board/lists` 경로를 쓴다(나머지는 `mgallery/board/lists`).

네이버 종목토론실은 종목 전용 게시판이라 제목 검색을 하지 않고 최신 글을 그대로 받는다.
검색어는 `FinanceDataReader`로 6자리 티커를 만드는 데만 쓴다.
뽐뿌는 제목 전용 검색 파라미터가 없어 본문까지 걸리므로, 제목에 검색어가 없는 글은
집계에서 제외한다.

### 점수와 구간

```
score = 50 + ((탐욕 키워드 수 - 공포 키워드 수) / 전체 게시글 수) * 50
```

구간은 CNN Fear & Greed와 같은 경계를 쓴다.

```
0~24 극단적 공포 · 25~44 공포 · 45~54 중립 · 55~74 탐욕 · 75~100 극단적 탐욕
```

원래 스펙은 중립을 41~60으로 뒀는데 폭이 20이나 돼서 실제 공포를 중립으로 덮었다.
지수가 18~38이고 섹터 13개 중 10개가 45 미만인 상황에서 전체 여론만 42.1로 "중립"이
나왔다. 같은 화면에 시장 지표(CNN 경계)가 나란히 있으니 자를 하나로 맞춰야 비교가
된다. 구간 정의는 `fomo_core.ZONES` 한 곳에만 두고 `fomo_market`과 프론트가 참조한다.

### 점수 계산

종목별 여론 점수는 축소 추정(shrinkage)을 쓴다.

```
점수 = 50 + (탐욕 - 공포)/(탐욕 + 공포) × 50 × n/(n + 12)     # n = 키워드 총합
```

방향은 키워드 비율로 잡고, 표본이 적을수록 중립인 50 쪽으로 당긴다. 원래 스펙의
수식(`분모 = 전체 게시글 수`)은 제목 200개에서 키워드가 5~10개만 잡히니 분자가 묻혀
30종목이 45.1~52.4(표준편차 1.65)에 몰렸고 라벨이 전부 `중립`이었다. 다섯 구간 중
한 칸만 쓰는 셈이다. 축소 추정으로 바꾸니 20.5~64.0(표준편차 10.87)으로 퍼졌다.

키워드 비율만 쓰면(`분모 = 키워드 합`) 표본 1개로 0점이나 100점이 찍힌다.
`n/(n+12)` 항이 그걸 수식 자체로 막는다. `SHRINK_K`를 키우면 보수적으로, 줄이면
민감해진다.

시장 전체와 섹터는 `sentiment_score`(분모 = 키워드 합)를 쓰고 표본 10회 미만이면
`표본 부족`으로 표시한다. 여러 종목을 합친 값이라 축소가 필요 없다.

**지수는 `index_score`를 쓴다.** 처음에는 지수도 표본이 두껍다고 보고
`sentiment_score`를 썼는데 실측이 달랐다. 태그율이 지수마다 3배씩 갈린다.

| 지수 | 게시글 | 키워드 히트 | 태그율 | 1건 흔들림 |
|---|---|---|---|---|
| 코스피 | 328 | 72 | 22.0% | 2.8 |
| 나스닥 | 355 | 66 | 18.6% | 3.0 |
| 코스닥 | 224 | 16 | 7.1% | **12.4** |
| S&P500 | 48 | 4 | 8.3% | — |

코스닥이 히트 16회로 탐욕 8 / 공포 8이 되어 50.0(중립)이 나왔다. 그런데 원글은
`[속보] 코스닥 700 붕괴`, `코스닥 2개월 만에 고점 대비 -42.84%`처럼 공포가
뚜렷했다. 균형을 만든 탐욕 쪽 `상한가` 5건은 전부 야간선물이나 개별 잡주 얘기였다
(`코스닥에 야스 << 상한가임`, `코스닥 잡주들 줄상한가간다`). 지수 심리와 성격이
다른 글이 같은 무게로 섞인 셈이다.

그래서 두 가지를 걸었다. 표본 하한을 `MIN_INDEX_HITS = 20`으로 시장·섹터(10)보다
높게 두고, 하한을 넘겨도 축소 추정을 적용한다. 코스닥의 흔들림이 12.4에서 7.2로
줄고, 표본이 두꺼운 코스피·나스닥은 1.6점 이내로 거의 그대로다.

표본 부족인 지수는 `표본 부족 (16/20)`으로 현재 히트 수를 함께 보여준다. `—`만
있으면 고장으로 읽힌다.

#### 표본을 더 못 모으는 이유

코스닥 히트를 20까지 올릴 방법을 전부 실측했다. 전부 막혔다.

**페이지를 늘려도 안 늘어난다.** 3일치가 이미 2페이지에서 소진된다.

```
arca        pages=2 -> 70건 태그2    pages=3 -> 70건 태그2
dc_krstock  pages=2 -> 68건 태그8    pages=4 -> 68건 태그8
ppomppu     pages=2 -> 34건 태그1    pages=4 -> 34건 태그1
```

**별칭도 없다.** `KOSDAQ` 0건, `코닥` 0건, `코스닥지수` 0건이었다. 한국 커뮤니티는
영문 표기를 안 쓴다.

**기간을 늘려도 하한에 못 미친다.** 3일 히트11 → 5일 히트15 → 7일 히트15로 포화한다.

**어휘를 추가해도 9건뿐이다.** 미태그 제목 697건을 읽어보니 대부분 감정 판정이
불가능한 글이었다(`나스닥 선물 현황`, `코스피 예상 ㅋㅋㅋ`, `코스닥98년도 가격?`).
안전하게 넣을 수 있는 말(`박살`, `좆됐`, `신저가`, `전저점`, `시체`, `지옥`)을 다
합쳐도 9건이다. 빈도가 높은 후보는 방향이 갈려 못 쓴다.

| 후보 | 탐욕 문맥 | 공포 문맥 |
|---|---|---|
| 빠지 | 나스닥은 빠지면 좋아해야함 | 나스닥 얼마나 더빠지려나 |
| 오르 | 내일 코스피 무조건 오르겟네 | 쳐오르다 빠지는거 보면 |
| 좋 | 코스피 야선 왜이리 좋음? | 코스피 3000되도좋으니 숏충이들 죽여주세요 |

커뮤니티에서 코스닥을 지수로 이야기하는 양이 원래 적다. 수집 방식 문제가 아니라
관심도 차이다.

### 지수별 뉴스 논조

그래서 지수 카드에 뉴스를 함께 붙였다. 커뮤니티가 얇은 곳을 뉴스가 메운다.

| 지수 | 커뮤니티 히트 | 뉴스 히트 |
|---|---|---|
| 코스피 | 68 | 95 |
| 코스닥 | 11 | 92 |
| S&P500 | 4 | 88 |
| 나스닥 | 63 | 123 |

**검색어는 `{지수} 지수`를 쓴다.** `주가`를 붙이면 개별 종목 기사가 섞인다. 실측에서
`코스닥 주가`는 태그 49건, `코스닥 지수`는 69건이었고 S&P500은 44 → 100건으로
벌어졌다.

**점수는 섞지 않는다.** 커뮤니티 여론과 뉴스 논조를 따로 보여준다. 성격이 다른
표본이라 합치면 어느 쪽이 움직였는지 알 수 없다. 접힌 카드에는 `뉴스 26.3 · 95회`로
요약만 두고, 펼치면 긍정/부정 기사를 두 열로 보여준다.

점수 하나로는 "한 종목이 끌고 가는 쏠림"과 "전반적인 온기"를 구분할 수 없어
기울기(탐욕 우세 / 공포 우세 종목 수)를 함께 낸다. 섹터별 심리는 공포가 심한
쪽부터 늘어놓는다.

### 종목별 점수는 화면에 내지 않는다

종목 점수는 계산은 하되 대시보드에 표시하지 않는다. 표본이 소수점을 보여줄 만큼
두껍지 않아서다.

**키워드 3개만 반대로 잡혔다면 30종목 중 24종목의 구간 라벨이 바뀐다.**

| 종목 | 키워드 히트 | 3개 차이의 결과 | 흔들림 |
|---|---|---|---|
| 월덱스 | 6 | 공포 ← 중립 → 탐욕 | 33.4 |
| HB테크놀러지 | 12 | 공포 ← 중립 → 탐욕 | 25.0 |
| 오로라 | 17 | 공포 ← 탐욕 → 탐욕 | 20.7 |
| S-Oil | 38 | 공포 ← 중립 → 탐욕 | 12.0 |

원인은 종목 표본의 **88.7%가 네이버 종목토론실 한 곳**에서 온다는 데 있다. 디시 4개
갤러리는 다 합쳐 1.6%다. 종목명으로 검색하면 커뮤니티에서는 거의 안 걸린다. 게시글
240개를 모아도 키워드는 30회 수준인데, 지수는 452개에 113회가 잡힌다. 지수 점수와
종목 점수는 신뢰도가 다른 숫자인데 같은 형식으로 나란히 놓이면 오해를 부른다.

표본이 두꺼운 종목(삼성전기 히트 86, SK하이닉스 81)은 회차 간 흔들림이 6점대로
안정적이다. 문제는 얇은 종목이라, 수집은 그대로 두고 화면 표시만 뺐다. 종목 데이터는
시장 심리 집계와 섹터 기울기의 재료로 계속 쓴다.

### 화면 구성

종목 표가 있던 자리에는 반응이 검증된 글을 둔다.

**지수 카드(4개)** 를 누르면 아래 전체 폭에 상세가 펼쳐진다. 회차·일별 추이, 많이
쓰인 말, 그 지수 화제글 24건, 소스별 수집 내역이 들어간다. 한 번에 하나만 열린다.
카드 안쪽에 넣지 않고 아래로 뺀 이유는 한 칸만 세로로 길어지면 나머지 세 칸 옆이
비고 목록도 좁은 폭에 눌리기 때문이다.

**시장 화제글** 은 에펨 인기글 60건을 반응순으로 펼친다. 탐욕/공포/태그 없음과
게시판으로 걸러 볼 수 있다.

피드는 점수 계산과 기준이 다르다. `feed_posts`는 키워드가 안 잡힌 글도 담는다.
인기글 60건 중 감정 키워드가 붙는 글은 **4건(7%)** 뿐인데, 나머지도
`진짜 다들 멘탈 어찌 잡아요? 3억 대출 받았는데 -7천됨`처럼 분위기를 분명히 담고
있었다. 키워드로 거르면 화제글의 93%가 사라진다. 무엇을 셀지와 무엇을 보여줄지는
별개다.

정치 공방 글만 피드에서 뺀다(`is_politics_post`). 추천 상위 3위 안에 2건이 있었지만
시장 분위기가 아니라 진영 싸움이었다. 단 `정부 "연기금아, 코스닥 바닥인데"`처럼
시장을 함께 말하는 글은 남긴다.

### 섹터별 뉴스 논조 (`fomo_news.py`)

커뮤니티 여론 옆에 뉴스를 나란히 둔다. **점수는 섞지 않는다.** 성격이 다른 표본이라
합치면 어느 쪽이 움직인 건지 알 수 없어진다. 커뮤니티는 사람들이 무슨 말을 하는지,
뉴스는 매체가 어떻게 쓰는지 말해준다.

구글 뉴스 RSS를 쓴다. 한국어 검색 한 번에 100건까지 오고 언론사도 연합인포맥스,
조선일보, 머니투데이, YTN처럼 실제 매체다. 네이버 금융 뉴스(HTTP 200), 한경
RSS(200), 매경 RSS(200)도 열리지만 섹터별 검색이 안 되거나 건수가 적었다.
이데일리 RSS는 SSL 오류다.

**감정 태그가 커뮤니티보다 훨씬 잘 잡힌다.**

| 표본 | 태그율 |
|---|---|
| 에펨 인기글 | 7% |
| 반도체 뉴스 | 41% |
| 로봇 뉴스 | 53% |

기사 제목은 `SK하이닉스 주가 폭락`처럼 방향을 명시하고 조롱·반어가 거의 없다.

**검색어는 섹터 이름을 쓴다.** 대표주 이름으로 검색하면 표본이 말라 종목 점수와 같은
문제가 재발한다(3일 기준 실측).

| 섹터 | 이름 검색 | 대표주 검색 |
|---|---|---|
| 기계 | 56건 | 5건 |
| IP | 50건 | 9건 |
| 식품 | 65건 | 3건 |

**`when:3d`가 없으면 쓸 수 없다.** 날짜 필터를 빼면 기사 나이 중위가 190일, 최대
1686일이었다. `기계 주가`로 검색했을 때 2021년 기사까지 올라왔다. 붙이면 중위 1일로
정리된다. 응답에 오래된 기사가 섞이는 경우가 있어 `pubDate`로 한 번 더 걸러낸다.

#### 뉴스용 어휘를 따로 둔 이유

커뮤니티 사전과 분리했다. `가즈아`는 기사에 안 나오고 `목표주가 하향`은 커뮤니티에
안 나온다. 한 사전에 섞으면 어느 표본에서 온 신호인지 알 수 없다.

기사 787건을 세어 빈도가 확인된 말만 넣었다. 상위 빈도는 급락(83) 하락(73) 상승(54)
강세(53) 급등(36) 폭락(27) 약세(25)였다.

후보에서 뺀 말들은 실제 문맥을 확인한 결과다.

| 제외 | 이유 |
|---|---|
| 조정 | `목표가 하향 조정`(부정)과 `밸류에이션 조정`(중립)에 함께 쓰인다 |
| 돌파 | `15만원 돌파`와 `돌파구 못 찾는`에 함께 쓰인다 |
| 회복 | `실적 회복 기대`와 `회복 어려워`에 함께 쓰인다 |
| 성장 | `성장 기대`와 `성장주 고평가 시대 끝나나`에 함께 쓰인다 |
| 리스크 | `리스크에도 불구하고 저평가`처럼 역접에 묻힌다 |

#### 역접 처리

기사 제목은 역접이 흔하다. 실측에서 `어닝 서프라이즈` 9건 중 3건이 뒤에 부정을
달고 있었다.

```
한화시스템, 2분기 어닝 서프라이즈에도 목표가 하향 이유는?
삼성전자, 2분기 반도체로만 89조원 역대 최대실적 냈지만…주가는 또 '주춤'
```

그대로 세면 긍정과 부정이 동시에 잡혀 상쇄된다. 기사의 결론은 뒤에 오므로 역접
(`에도`, `지만`, `고도`) 앞부분을 버린다.

역접 어미가 없는데 호재를 무력화하는 표현도 있다(`실적 호재도 소용 없다`,
`어닝 서프라이즈도 안 통했다`). `NULLIFIED` 패턴이 걸리면 긍정을 버린다.

#### 화면

섹터 탭 14개를 부정이 심한 쪽부터 늘어놓고, 고른 섹터의 긍정/부정 기사를 두 열로
나눠 보여준다. 각 열에 최대 10건, 최신순이다. 뉴스는 반응 수치가 없어 시간이 유일한
순서 신호다.

태그 없는 기사는 목록에 담지 않는다. 태그율이 41~53%라 태그된 것만으로 충분하다.
커뮤니티 피드와 다른 선택인데, 그쪽은 태그율이 7%라 거르면 표본이 사라진다.

표본이 8회(`MIN_HITS`) 미만인 섹터는 점수를 내지 않는다. 커뮤니티 지표와 같은
원칙이다. 수집이 막힌 섹터는 전체 점수 계산에서 뺀다.

### 시장 지표 (CNN Fear & Greed 방식)

여론과 별도로 가격 데이터 기반 지표를 둔다. 여론은 사람들이 무슨 말을 하는지,
가격 지표는 시장이 실제로 어떤 상태인지 말해준다. `fomo_market.py`가 계산한다.

| CNN 원본 | 국내 대응 | 20일 수익률과 상관 |
|---|---|---|
| Market Momentum | 코스피 vs 125일선 | +0.86 |
| Market Volatility | 20일 실현변동성(역) | +0.33 |
| Stock Price Breadth | 상승 종목 비율 | 0~100 척도 |
| 52-Week High/Low | 코스피 52주 레인지 내 위치 | +0.91 |
| (추가) | RSI(14) | +0.76 |

**환율과 금, VIX는 넣지 않았다.** CNN의 Safe Haven Demand를 원달러로 옮기려 했지만
코스피와 원달러 일간 수익률 상관이 **+0.457**로 같은 방향이었다(교과서와 반대).
금(+0.19), TLT(+0.07), VIX(-0.07)도 유효한 역상관이 없었다. 실제로 이 지표를 넣고
계산했을 때 코스피가 125일선 대비 -18%인 급락장에서 환율이 100점을 찍어 전체
점수를 34.2까지 끌어올렸다. 빼고 나니 21.2(극단적 공포)로 실제와 맞았다.

이론상 맞는 지표라도 데이터가 뒷받침하지 않으면 넣지 않는다. VKOSPI는 조회가
되지 않아 일간 수익률로 실현변동성을 직접 계산한다.

정규화는 과거 1년 분포의 백분위다. 절대 임계값을 두면 국면이 바뀔 때마다 기준을
손봐야 하지만 백분위는 "최근 1년 중 어느 수준인가"를 그대로 말해준다. 구간 경계는
CNN과 같다(25/45/55/75). 지표 하나가 조회 실패하면 나머지 평균으로 계산한다.

### 지수

코스피, 코스닥, S&P500, 나스닥은 `fomo_indices.py`에 정의하고 종목과 다르게 다룬다.

```bash
python fomo_scanner.py 코스피
python fomo_scanner.py 나스닥
```

지수는 부르는 말이 갈린다. `S&P500`만 검색하면 202개 중 71개만 잡히고, `에센피`와
`SPY`를 함께 검색해야 표본이 채워진다(실측). 그래서 별칭을 묶어 검색한 뒤 제목
기준으로 합친다. 같은 글이 두 별칭에 모두 걸리면 한 번만 센다.

수집 기간은 지수마다 다르다. 코스피와 코스닥은 종목과 같은 3일이고, S&P500과
나스닥은 7일(`US_INDEX_LOOKBACK_DAYS`)이다. 국내 커뮤니티에서 미국 지수 언급이
훨씬 드물어 3일로 자르면 S&P500이 25개(키워드 3회)만 남는다. 국내 지수는 표본이
충분하니 시장 심리와 같은 기간으로 두어 나란히 읽을 수 있게 했다.

네이버 종목토론실은 6자리 코드가 없어 자동으로 빠진다. 지수 전용 디시 갤러리
(`kospi`, `kosdaq`, `snp500index`, `dow100`)는 붙이지 않았다. 실측에서 코스닥
갤러리는 2024-08, S&P 갤러리는 2025-04에 마지막 글이 올라와 사실상 죽어 있다.
대신 기존 8개 소스에 지수 키워드로 검색하면 지수당 200~330개가 모인다.

지수는 표본이 두꺼워 `sentiment_score`를 바로 쓴다. 종목처럼 게시글 수로 나누면
역시 50에 붙는다.

### 원글 확인

점수만 보여주면 근거를 확인할 길이 없다. 키워드가 실제로 잡힌 글을 링크와 함께
남기고, 마우스를 올리면 팝오버로 뜬다. 제목을 클릭하면 해당 게시판 원문으로 간다.
시장 요약의 `원글 N개`, 지수 카드, 종목명(표) 또는 `원글 N개`(카드)에 붙어 있다.

접었다 펴는 방식이 아니라 팝오버로 둔 이유는 레이아웃이다. 목록이 인라인으로
펼쳐지면 아래 내용이 밀려 내려가 다른 카드나 종목과 비교하기 어렵다. 팝오버는
화면 오른쪽이나 아래로 넘칠 때 위치를 뒤집고, 마우스가 트리거에서 패널로
옮겨가는 동안 닫히지 않게 짧은 지연을 둔다. `Esc`로도 닫힌다.

수집한 글 대부분은 키워드가 없어 점수에 영향을 주지 않으므로 전부 저장하지 않는다.
한쪽으로 치우친 목록은 분포를 오해하게 만들어 탐욕/공포를 번갈아 담고, 키워드가
여러 개 잡힌 글을 앞에 둔다.

### 반응(조회수·추천) 가중

조회수도 없는 글과 수백 명이 추천한 글을 같은 한 표로 세면 여론이 아니라 글 쓴
사람 수를 재는 것이 된다. 목록에서 조회수·추천·댓글을 함께 읽어 무게를 조절한다.

```
화제글(소스 중위 조회수 x3 이상 또는 추천 중위 x3 이상)   3표
보통 글                                                  1표
조회수가 소스 중위의 40% 미만이고 추천·댓글이 0            제외
수치를 읽지 못한 글                                       1표 (셀렉터가 깨져도 표본을 지킨다)
```

**절대 임계값은 못 쓴다.** 같은 3일치 코스피 표본에서 조회수 중위가 디시 미국주식
46, 디시 한국주식 83, 아카라이브 121, 에펨 204, 뽐뿌 792였다. 스케일이 20배 차이
나므로 하나의 숫자로 자르면 뽐뿌만 남는다. 소스별 중위값 대비 배수로 판단하고,
중위값은 표본 8개 이상일 때만 신뢰한다.

**추천수는 필터로 쓰지 않는다.** 디시는 86%가 추천 0이고, 뽐뿌·에펨 인기글은 추천
칸의 스케일이 아예 다르다(에펨 인기글 중위 80, 디시 중위 0). 추천은 무게를 더하는
쪽으로만 쓴다.

효과는 실측으로 확인했다. 같은 표본에서 가중만 켜면 코스피 24.7 → 26.6, 나스닥
31.9 → 39.5로 움직였다. 나스닥이 더 크게 변한 건 조회수가 높은 글에 탐욕 쪽
표현이 몰려 있었기 때문이다. 전체 회차에서 인기글은 7440개 중 1357개, 반응이 없어
제외된 글은 253개였다.

하한을 더 세게 걸어 표본을 30% 버리는 방식도 재봤지만 점수는 4점 남짓 움직이면서
표본만 얇아졌다. 버리는 대신 무게를 주는 쪽이 같은 목적에 손실이 적다.

화면에는 시장 요약과 지수 카드에 `인기글 N개 · 제외 N개`로, 원글 목록에는 글마다
조회수·추천·댓글 아이콘으로 표시한다.

### 에펨 인기글 (시장 심리 전용)

검색으로는 안 잡히는 화제글이 있다. `삼전본주 -39% 대인데 엄살인거지?`처럼 종목명을
정확히 쓰지 않은 글이다. 에펨 주식 게시판의 추천순 목록(`sort_index=pop`)을 검색어
없이 받아 회차당 60개를 보탠다.

**개별 종목에는 섞지 않는다.** 인기글은 종목을 특정하지 않으므로 30종목이 같은
표본을 공유하게 된다. 지수 별칭으로 걸러봤을 때는 60건 중 2건만 남아 표본이
사라졌다. 그래서 여러 종목을 이미 합치고 있는 시장 심리에만 더한다.

이 목록은 **이미 추천순으로 걸러져** 있어 상대 기준을 다시 적용하지 않는다. 실측에서
추천 중위가 92라 그 3배(276)를 넘는 글이 하나도 없어 전부 보통 글로 판정됐다.
커뮤니티가 골라준 목록이므로 전부 화제글로 본다.

비중은 확인해뒀다. 인기글 60개가 기여하는 키워드는 전체의 2.8%로, 시장 심리를
41.3에서 40.2로 옮기는 정도다. 60개 글이 30종목을 압도하지 않는다.

### 키워드 사전을 고른 기준

원글을 확인할 수 있게 되면서 초기 사전의 문제가 드러났다.

`간다`, `진입`, `사도`는 빼냈다. 방향을 담고 있지 않아서다. 실측에서 `간다` 33건 중
절반이 "10만원 아래 간다", "코스피 5000 간다"(6월 고점 9115에서 33% 내려온 상황의
조롱)처럼 하락을 뜻했고, `진입` 19건 중 절반이 "손실 구간 진입", "조정 국면 진입"
이었다. 세 단어가 전체 탐욕의 54%를 차지했으니 왜곡 규모도 작지 않았다.

대신 은어와 일반 시장 어휘를 함께 담았다. 제목 760개를 세어보니 `가즈아`나 `떡상`
같은 커뮤니티 은어는 0~1회인데 `반등`(15) `상승`(14) `폭락`(13) `급락`(8)처럼
평범한 말이 훨씬 많이 쓰였다. 은어만 남기면 표본이 탐욕 2회 수준으로 말라
지표를 낼 수 없다.

`매수`, `바닥`, `조정`은 후보에서 제외했다. "바닥 잡았다"와 "바닥이 안 보인다"처럼
양쪽에 같은 빈도로 쓰여 방향을 담지 못한다.

`NEGATED_PATTERNS`는 뒤에 붙는 말이 뜻을 뒤집는 경우(`신고가 경신 실패`,
`불장은 끝났다`)만 걸러낸다. 문맥 판정을 더 밀고 나가면 규칙이 지표보다 복잡해진다.

### 문맥 판정

같은 단어라도 문맥이 뜻을 뒤집는다. 탐욕으로 분류된 139건을 직접 검토해 네 유형을
찾아냈고, `greed_is_credible()`이 이를 걸러낸다.

| 유형 | 예 | 규칙 |
|---|---|---|
| 자조 | `코스피 5천 가즈아 ㅋㅋㅋㅋㅋ` | `SARCASM_PATTERN` |
| 하락 문맥 | `폭락후 소폭반등`, `장초 하락때 풀매수했는데` | `is_mixed_context` |
| 어긋난 기대 | `오늘은 소폭 반등할 줄 알았는데` | `is_unfulfilled` |
| 부정과 역설 | `하한가 가즈아`(저격), `가짜 상승`, `호재가 아니야`, `제발 코스닥 반등` | `is_inverted` |
| 하락 목표 | `코스피 4000대 가즈아`(지수 6053) | `targets_below_current` |

마지막 규칙은 숫자를 현재 수준과 비교한다. `코스피 4000대 가즈아`는 지수가 6053일 때
33% 아래로 내려보내자는 조롱이지만, 코스피 3000 시절이라면 진짜 기대였다. 같은
문장이라도 단어만으로는 가릴 수 없고 현재 값을 알아야 판정된다.

지수 현재값은 `FinanceDataReader`로 받아 6시간 캐시하고(`fomo_indices.index_levels`),
종목은 대시보드 JSON의 `quote.close`를 쓴다. 현재값을 모르면 이 규칙은 관여하지 않는다.

비율과 수량은 목표 수치로 보지 않는다(`10%빠진`, `445주`, `2주간`). 현재 수준과
자릿수가 10배 이상 다른 숫자(연도, 종목코드)도 건너뛴다. 과거 경로를 말하는 문장
(`4천에서 2000포인트 오른거다`)은 목표가 아니라 서술이라 제외한다.

네 규칙은 탐욕에만 적용한다. 공포 표현은 같은 문맥에서 뜻이 그대로거나 오히려
강해진다(`3일만에 반토막 ㅋㅋㅋ`, `실시간 나스닥대폭락ㅋㅋㅋ`).

두 방향이 섞인 문장은 억지로 한쪽에 넣지 않고 탐욕 판정을 포기한다. `급락하면
무조건 다음날 상승`에서 글쓴이 심리를 규칙으로 가릴 수는 없고, 잘못 세는 것보다
세지 않는 편이 정확하다. 공포는 그대로 센다.

사람이 쓰지 않은 글도 뺀다. 네이버 종목토론실 알림봇이 `5% 이상 상승했어요 🎉`를
반복해서 찍는데, 탐욕 139건 중 24건(17%)이 이 형태였다. 시세를 옮긴 것이라 여론이
아니고 한 종목에 여러 번 찍혀 표본을 왜곡한다(`BOT_PATTERNS`).

`상승종목 148개 하락종목 739개`처럼 시세 집계를 옮긴 제목도 같은 이유로 제외한다
(`TALLY_PATTERN`).

한 사이트가 막혀도 나머지로 계산을 진행하고, 실패한 사이트는 사유와 함께 표시한다.
같은 사이트가 세 종목 연속 실패하면 남은 종목에서는 요청하지 않는다. 차단된 곳을
계속 두드리면 차단이 길어지기 때문이다. 특히 에펨코리아는 쿼터가 빡빡해서
`fomo_core.py`의 `DOMAIN_MIN_INTERVAL`로 도메인별 최소 요청 간격을 강제한다.

## 4. 괴리 따라잡기 백테스트

`백테스트` 탭은 "한국이 미국을 따라간다"는 전제를 과거 데이터로 채점한다.

```bash
python catchup_backtest.py
```

`frontend/public/backtest_data.json`이 갱신된다. 2020년 이후 전 구간을 훑으므로
갱신 주기를 둘 필요는 없고, 그룹 구성을 바꿨을 때만 다시 돌리면 된다.

### 괴리를 재는 방법

괴리는 로그 상대지수로 잰다. `rel = log(국내 체인지수) - log(해외 체인지수)`.
기준일 100 정규화와 달리 시작일을 옮겨도 값이 평행 이동만 하므로, 6년 표본에서
"언제부터 봤느냐"에 따라 괴리 폭이 달라지지 않는다. 인덱스는 커플링 계산과 같은
`chain_index()`를 써서 상장 시점 차이로 생기는 점프를 없앤다.

에피소드(괴리 사례) 조건은 두 개를 함께 본다.

- 60일 이동평균 기준선에서 `|Z| >= 1.5`
- 기준선과의 괴리가 5%p 이상

Z만 쓰면 조용한 구간에서 0.5%p 차이가 신호로 잡힌다. 되돌림을 재도 의미가 없는
크기라 최소 괴리 폭을 함께 걸었다. 한 번 잡은 신호는 절반 회복하거나 60거래일이
지날 때까지 다시 잡지 않는다. 같은 괴리를 여러 번 세면 표본이 부풀고 성공과 실패가
함께 복제된다.

### 결과를 읽는 방법

회복률 = `-(rel 변화) / 신호 시점 괴리`. 방향을 흡수한 값이라 국내가 뒤처졌든
앞섰든 같은 자로 읽을 수 있다.

| 값 | 뜻 |
|---|---|
| 1.0 | 기준선까지 완전히 되돌아옴 (완전 수렴) |
| 0.5 | 괴리의 절반을 좁힘 (탭에서 "따라잡음"으로 세는 기준) |
| 0 | 그대로 |
| 음수 | 괴리가 더 벌어짐 |

표본 끝에 걸려 60거래일을 채우지 못한 진행 중 건은 `resolved: false`로 남기고
성공률 계산에서 뺀다. 넣으면 최근 사례가 전부 실패로 잡힌다.

### 실측 결과

2020년 이후 커플링 유효 그룹 30개, 확정된 괴리 사례 1,183건 기준이다.
표본이 1,000건을 넘어 합산 통계는 오차가 ±3%p로 좁다. 여기서는 단정할 수 있다.

| 지표 | 값 | 95% 구간 |
|---|---|---|
| 60일 안에 수렴에 **닿음** | 59% | 57~62% |
| 60일 시점에 수렴 **유지** | 34% | 31~37% |
| 60일 절반 회복 | 43% | 41~46% |
| 20일 절반 회복 | 35% | 33~38% |

**괴리는 좁혀지되 머물지 않는다.** 26%p가 수렴에 닿았다가 되돌아간다. 두 구간이
겹치지 않으므로 확정이다. 절반 회복까지는 중위 7거래일이 걸리지만, 60일 시점에
절반이라도 유지한 경우는 43%로 우연(50%)보다 **확실히 낮다**.

커플링 자체는 실재한다(30/32 그룹이 `moderate` 이상, 표본 1,600일로 오차 ±0.03).
연동은 확실하지만 그것이 수렴을 뜻하지는 않는다는 것이 이 백테스트의 결론이다.
`analysis/signal_backtest.py`의 44~48%와 같고, 로그 상대지수·장기 표본·시총가중으로
바꿔도 43~45%였다.

### 조건을 갈라도 결과가 같다

무효 결과지만 "괴리가 크면 더 좁혀진다" 같은 직관을 반박하는 근거라 탭에 함께 싣는다.
세 축 모두 신뢰구간이 겹친다. 즉 **차이가 없다는 것이 확인됐다**.

| 축 | 대비 (60일) |
|---|---|
| 방향 | 국내 뒤처짐 43% (39~47) vs 앞섬 43% (40~47) |
| 괴리 크기 | 5~8%p 46% (42~50) vs 12%p 이상 42% (36~48) |
| 커플링 등급 | 강 45% (40~50) vs 중 43% (39~46) |

괴리 크기나 커플링 등급으로 진입 시점을 고를 근거가 없다는 뜻이다.

### 그룹에 등급을 매기지 않는 이유

그룹별 표본은 30~55건뿐이라 비율 하나로 순위를 만들 수 없다. `PCB/기판` 57%의
95% 구간은 43~70%이고, 꼴찌 `변압기/전력기기` 31%는 19~46%다. **두 구간이 겹치므로
통계적으로 구분되지 않는다.** 기간을 반으로 갈라보면 순위가 실제로 뒤집힌다
(전반기 상위 5개 중 후반기에도 남는 건 1개, Kendall tau -0.18).

그래서 그룹 표에는 등급을 붙이지 않는다. 비율 옆에 Wilson 95% 구간을 함께 놓고
색도 쓰지 않는다. 구간이 겹치는지는 보는 사람이 판단한다. 기본 정렬은 표본 크기
(`괴리 사례`)로 두어, 비율 1위가 가장 좋은 그룹처럼 읽히지 않게 했다.

합산 통계(표본 1,183건)는 다르다. 구간이 ±3%p로 좁아 50%보다 낮다고 단정할 수
있으므로 상단 결론 카드에서는 색을 쓴다.

### 현재 괴리

사례 목록 첫 줄은 **지금 상태**다(`현재` 표시). 과거 사례와 같은 기준선·Z로 재므로
바로 비교할 수 있다. 결과가 없는 건이라 회복률 대신 `진행 중`과 현재 Z를 놓고,
에피소드 조건(|Z| ≥ 1.5 그리고 괴리 ≥ 5%p)을 충족하면 `괴리 확대`로 표시한다.

현재 건의 차트는 신호 이후 구간이 없다. 마지막 날을 100으로 잡으면 두 선이 끝에서
붙어 괴리가 0으로 보이므로, **구간 시작을 기준으로 잡아** 지금까지 벌어진 폭이
오른쪽 끝에 드러나게 한다. 그래서 표의 괴리(기준선 대비)와 차트의 괴리(구간 시작
대비)는 값이 다르고, 차트 라벨에 어느 기준인지 함께 적는다.

### 괴리 탭과의 관계

두 탭은 겹쳐 보이지만 다른 질문에 답한다.

| | 괴리 탭 | 백테스트 탭 |
|---|---|---|
| 질문 | 지금 무엇을 볼까 | 이 신호가 통했나 |
| 표본 | 최근 6개월 | 2020년~ (6년) |
| 인덱스 | 기준일 100 정규화 | 로그 상대지수 |
| Z 윈도우 | 20일 | 60일 |

기준이 다르므로 **같은 그룹의 Z가 두 탭에서 다르게 나온다.** 실측에서 32개 중
10개가 갈렸고, `반도체 소재`는 부호까지 반대였다(괴리 탭 +1.66 / 백테스트 -0.67).
국내가 6개월 내내 뒤처져 있지만 최근 20일로는 좁혀지는 중이라 그렇다. 둘 다 맞는
값이라 통일하지 않고, 현재 괴리 차트 위에 어느 기준인지 명시했다.

커플링은 `peer_tracker.py`의 `coupling_stats()`가 단일 출처다. 백테스트 탭은 그룹을
걸러내는 등급(`tier`)만 쓰고 상관 수치는 표시하지 않는다. 두 곳에서 같은 값을
내려보내면 실행 시각이 어긋날 때 탭마다 다른 숫자가 보인다(실측 0.58 vs 0.59).

행을 누르면 그 그룹에서 괴리가 컸던 사례 8건이 시점, 방향, 회복률,
국내-해외 초과수익과 함께 펼쳐진다. 거기서 **시점을 누르면 그 시점 전후 차트**가
열린다. 신호 이전 60거래일과 이후 선택 구간(20일 또는 60일)을 잘라 해외/국내
지수를 겹쳐 그리고, 신호일을 100으로 다시 잡아 그 시점 이후 누가 얼마나 갔는지
두 선의 벌어짐으로 보여준다. 선 위에 마우스를 올리면 그 날짜의 국내-해외 괴리가 나온다.

괴리 표시는 표의 `국내-해외`와 같은 로그 차분으로 계산한다. 정규화 지수를 그대로
빼면 같은 시점에 두 숫자가 어긋난다(60일 기준 -7.4%p vs -5.5%p).

차트 원자료는 `series`(날짜/해외/국내 배열)로 그룹당 한 벌만 싣고 프론트가 구간을
자른다. 에피소드마다 윈도우를 따로 실으면 구간이 겹쳐 파일이 4배 커진다.
시계열이 들어가면서 JSON이 1.6MB가 되므로 이 파일만 들여쓰기 없이 저장한다
(`indent=2`로 쓰면 3.5MB).

## 계산 방식

1. 티커별 수정 종가를 날짜 union으로 합치고 `ffill` - 미국/독일/스위스/한국 휴장일 차이로 스프레드가 튀는 것을 막는다.
2. 그룹 내 전 종목 데이터가 갖춰진 첫 거래일을 100으로 정규화한 뒤 종목 평균 = 그룹 인덱스.
3. `spread = lag_index - lead_index`, 20일 rolling 평균/표준편차로 Z-Score.
4. `|Z| >= 1.5`이고 커플링이 `strong` 또는 `moderate`이면 `alert: true`.
   임계는 넘었지만 커플링이 약한 경우는 `z_extreme: true, alert: false`로 구분한다.
   양수는 오버슈팅(국내 과열), 음수는 언더슈팅(국내 갭 확대).
5. 국내(lag) 종목에서 두 종목을 따로 뽑는다. 최근 6개월 상대강도(RS) 1등이
   `bellwether_ticker`(주도주), 시가총액 1등이 `top_pick_ticker`(대장주)다.
   두 선정은 서로 독립이라 같은 종목일 수도 있다. `bellwether_index`는 RS 1등
   종목만 100 정규화한 지수, `rest_index`는 그 종목을 뺀 나머지 평균이다.
   Top Pick은 표시 전용이고 인덱스 계산에는 관여하지 않는다.
6. `internal_spread = rest_index - bellwether_index`이고 같은 20일 Z-Score로
   `bellwether_z_score`를 낸다. 음수일수록 주도주만 앞서간 상태(나머지가 덜 오름,
   추격 매수 여지)이고 양수는 나머지가 주도주보다 앞선 순환매 확산이다.
   `|internal Z| >= 1.5`이면 `bellwether_alert: true`.
   국내 종목끼리의 관계이므로 해외-국내 커플링 등급으로 게이팅하지 않는다.

## 커플링 강도

스프레드가 좁혀진다는 가정은 두 그룹이 실제로 동행할 때만 성립한다.
2020년 이후 일간 수익률로 그룹별 커플링을 측정해 등급을 매긴다.

등급은 동행 상관(`corr`)과 시차 1일 상관(`corr_lag1`) 중 강한 쪽(`strength`)으로 정한다.

- `strong` (strength >= 0.30)
- `moderate` (>= 0.15)
- `weak` (< 0.15)

미국 장이 먼저 닫히는 그룹은 전달이 다음 거래일에 나타나므로 동행 상관만 보면
실제 연결을 놓친다. 예를 들어 미국 방산은 `corr` 0.13이지만 `corr_lag1`은 0.28이다.
`lead_channel`이 `same_day`인지 `next_day`인지로 어느 채널이 지배적인지 구분하고,
카드에는 그 채널을 강조해 표시한다.

방산은 시트가 유럽/미국 표를 따로 두었으므로 두 카드를 유지한다.
같은 국내 그룹을 양쪽 lead에 각각 연결해 어느 지역이 더 강하게 선행하는지 비교한다.

티커 상장 시점이 다르므로(GEV 2024-03, CEG/SMR 2022, 실리콘투 2021-10, RKLB 2020-11)
커플링 계산에는 `chain_index()`를 쓴다. 각 날짜에 존재하는 종목의 수익률만 평균해
누적하므로 신규 편입 시 인덱스 점프가 생기지 않는다.
스프레드 계산은 기존 교집합 방식(`build_group_frame`)을 그대로 쓴다.

### 검증 결과

`analysis/signal_backtest.py`로 2년 구간 `|Z| >= 1.5` 신호 1,290건을 확인한 결과,
스프레드 축소 비율은 5일 후 47.9%, 10일 후 46.1%, 20일 후 44.6%였다.
공적분 검정도 11개 그룹 전부 `p > 0.05`로 평균회귀를 지지하지 않았다.
따라서 Z-Score는 단독 매매 신호가 아니라 커플링 등급과 함께 읽어야 한다.

상수는 `peer_tracker.py` 상단(`LOOKBACK_DAYS`, `Z_WINDOW`, `ALERT_THRESHOLD`, `SLEEP_SEC`)에서 조정한다.
